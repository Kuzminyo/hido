# Hido

Прячет лишние иконки в строке меню macOS — в духе Hidden Bar, в стиле macOS.

**[⬇️ Скачать последнюю версию](https://github.com/Kuzminyo/hido/releases/latest)** — файл `Hido-x.y.zip` в разделе Assets.

- В строке меню появляются стрелка **›** и тонкая черта **|** слева от неё
- Зажмите **⌘** и перетащите ненужные иконки **левее черты**
- Нажмите на стрелку — всё левее черты спрячется. Нажмите ещё раз — появится
- На macOS 27 иконки исчезают так же, как в Hidden Bar: macOS сама прячет нужные приложения и перестраивает строку меню, без лишних стрелок. Для этого Hido нужен «Универсальный доступ» — без него иконки уходят в системную кнопку **«**
- Иконки прячутся обратно сами через 10 секунд (можно 5, 30 или никогда)
- Можно включить показ при наведении курсора на строку меню
- Правый клик по стрелке — настройки, подсказка, автозапуск и выход
- Защита: если черта случайно окажется правее стрелки, Hido не спрячет саму стрелку

Нужна **macOS 26 (Tahoe)** или новее. Работает на Mac с Apple Silicon и Intel.

## Установка готового приложения

1. Скачайте и распакуйте `Hido-x.y.zip` и перетащите **Hido.app** в папку «Программы».
2. Приложение не подписано сертификатом Apple, поэтому при первом запуске macOS его заблокирует.
   Откройте Терминал и выполните:
   ```bash
   xattr -cr /Applications/Hido.app
   ```
   Или: попробуйте открыть Hido → «Системные настройки» → «Конфиденциальность и безопасность» → внизу «Всё равно открыть».
3. Запустите Hido — появится подсказка, как перетащить иконки.
   Разрешите Hido «Универсальный доступ» («Системные настройки» → «Конфиденциальность и безопасность»), чтобы иконки прятались без системной кнопки «.
4. Автозапуск — правый клик по стрелке → «Запускать при входе».

## Сборка из исходников

Нужен Xcode 26 или новее.

```bash
./build.sh install
```

`./build.sh dist` собирает универсальную версию и архивы для отправки в папку `dist`.
